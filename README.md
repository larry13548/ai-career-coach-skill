# AI 简历与面试指导 Skill

第一版试用包 `0.1.0`：面向互联网行业应届生与社招，提供简历创建、JD定向优化、可编辑Word输出、面试辅导与模拟面试。

## 在豆包试用
首选豆包PC工作模式。按你当前版本可用的技能链接入口添加包含本仓库 `SKILL.md` 的GitHub仓库链接，确认相关references、assets和scripts也能访问；具体入口以实际客户端为准。此前用户验证过该方式，但本版本仍需在豆包中实际调用验证。仓库链接：https://github.com/larry13548/ai-career-coach-skill 。

本地交付的 `dist/ai-career-coach-skill-0.1.0.zip` 含技能目录及资源。如果客户端提供本地技能导入，可解压后导入整个目录；仅支持GitHub链接时，使用上方仓库链接。上传规则文本试跑不能当作真实安装测试。

调用示例：
- “我没有简历，想申请这个岗位，请引导我创建简历。”附JD。
- “根据这个JD分析并修改我的简历。”附简历和JD。
- “基于这份简历和JD，开始模拟面试。”

文字流程无需固定API。Word工具需要宿主提供文档生成能力，或Python 3与python-docx；联网和语音依赖宿主实际支持。未提供的能力会明确报告，不假装完成。

## 规则
- 有引导、有总结确认，正文确认后生成Word。
- JD逐项匹配：已匹配1分、部分匹配0.5、待确认及明确不匹配暂计0；加分项单列，固定清单。超过90%建议投递，硬性缺口优先提醒。
- 只写原材料和用户补充的事实；发现矛盾提示核实，未知项不猜改。
- 模拟面试逐题问答，最近经历约80%，单个主问题最多两轮追问，30分钟为目标；结束反馈2—3个影响录用判断的核心问题。

## 文件与本地检查
入口为 `SKILL.md`；详细规则在 `references/`；Word模板在 `assets/`；计算与文档工具在 `scripts/`。

以下命令在完整开发仓库中运行（技能ZIP只包含运行所需文件）：

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/package_skill.py
```

本地检查证明脚本可用及本地渲染表现，不代表豆包调用、复杂视觉保留或面试效果全部通过。完整检查记录见开发仓库的 `docs/development-report.md`。

原始候选人材料和输出保存在Git排除目录，只用于本地测试；发布包按白名单构建，不包含它们。当前为第一版试用版本。仓库暂未指定开源许可证。
